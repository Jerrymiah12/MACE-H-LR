# MACE-H-LR

MACE-H-LR learns short-range electronic Hamiltonians and combines them with an
analytic long-range response for MgO. It also computes Cartesian atomic-orbital
electron–phonon coupling by finite differences. The project derives from
[MACE-H](https://github.com/maurergroup/MACE-H) and
[DeepH-E3](https://github.com/Xiaoxun-Gong/DeepH-E3); see `NOTICE` for lineage.

## Install

Python 3.10 or newer is required; CI covers 3.10 and 3.12. GPU users should
install the PyTorch build matching their CUDA driver before installing this
project.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e '.[test]'
```

The equivalent Conda bootstrap is `conda env create -f environment.yml`.

## Smoke test

The committed synthetic canary checks DFPT parsing, the acoustic sum rule,
short-range error scoring, and one EPC tensor element against golden values:

```bash
python -m pytest -q tests/smoke
```

Run the default CPU suite with:

```bash
python -m pytest -m 'not slow and not gpu and not dft and not bigdata'
```

When the external dataset and run roots are available, exercise a real model
step and the two-epoch production path with:

```bash
python -m workflows.training.smoke_onebatch --device cpu
python -m workflows.training.smoke_production --target sr --epochs 2 --device cpu
```

## Commands

The installed CLI replaces the former `deephe3-*.py` scripts:

```bash
maceh preprocess configs/preprocess.ini
maceh train configs/train.ini
maceh eval configs/eval.ini
maceh epc workflows/epc/sr.ini
```

Dataset campaigns are kept outside the library and run as modules:

```bash
python -m workflows.mgo_dataset --help
```

## External data and runs

The 134 GB reference dataset and roughly 65 GB of generated caches/checkpoints
are not stored in Git. Point the project at them explicitly:

```bash
export MACEH_DATA_ROOT=/path/to/reference-data
export MACEH_RUNS_ROOT=/path/to/generated-runs
```

The ignored `data/` and `runs/` paths may be symlinked to those locations for
INI files that use repository-relative paths. See [docs/DATA.md](docs/DATA.md)
before moving or regenerating anything.

## Reproduce a committed-data figure

This command reads the committed learned-response metrics only; it does not
need the large data trees:

```bash
python -m workflows.analysis.reproduce_summary
```

It writes `results/learned_response/reproduced_summary.{png,pdf}`. The larger
campaign figures and decks are generated by the other modules under
`workflows/analysis/` and require the run inputs named in their manifests.

## Repository map

- `src/maceh/`: installable library; never imports campaign code.
- `workflows/`: dataset, training, EPC, and figure campaigns.
- `tests/`: unit, integration, smoke, and tiny fixtures.
- `results/`: curated scientific outputs and provenance manifests.
- `provenance/`: frozen identity of the external MgO dataset.
- `docs/`: architecture, data contract, designs, and archived reviews.

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the dependency boundary.
